COGS Auto-Matcher (v3)
Python · Pandas · Excel · Business Requirements Analysis

Documented the cost-matching requirements across multiple SKU naming conventions used by the business, then designed and delivered a 3-strategy cascade that covers all real-world edge cases, eliminating hours of manual cost lookup per week.

  • Requirements identified: 3 distinct SKU naming patterns each embedding cost data differently, required separate extraction logic per format
  • ASIN Match: copies cost from another row sharing the same ASIN
  • SKU Match: extracts the cost value embedded in the SKU string (e.g. OA2026_date_79.97_...)
  • A2A Match: parses A2A-format SKUs for canonical cost position, disambiguating from dates and item IDs
  • Outputs annotated Excel with Source column and match-method notes, auditable by non-technical staff

Live · AWS Deployed Web Application
PGMC Lab Scheduler

A Streamlit web application managing shift schedules for a 25-person clinical laboratory at PGMC, actively used by a real client. Requirements were gathered directly from the department head: shift rules, leave categories, cross-cutoff fairness constraints, and night coverage minimums. The system translates those business rules into a 7-step generation algorithm, deployed on AWS EC2 with IP-restricted access and Excel export for the non-technical department head.

Business Requirements Met
  • Stakeholder requirements gathered from PGMC clinical lab department head
  • Leave types (VL, SL, OB, TR, HOL) mapped across two 15-day cutoff periods
  • Cross-cutoff streak carry, prevents back-to-back 5-day streaks across month boundaries
  • Fairness debt tracking, equalises night and weekend shift distribution
  • Color-coded Excel export for non-technical review and approval
Technical Delivery
  • 7-step generation pipeline: request locks → fairness debt → night coverage → streak validation
  • AWS EC2 deployment, IP-restricted access, nginx serving, automated start/stop scheduling
  • Password-protected web interface, secure, accessible from any browser
  • Excel export/import with openpyxl, dept head never needs to touch the system's internals
  • AI-assisted development via Claude Code, full documentation provided on delivery
